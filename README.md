# Java Programming Archive

A categorized archive of historical Java coursework and experiments.

## Important notes
- This repository is an **archive**, not one single Java application.
- Files may be independent exercises, partial assignments, alternate versions, or classes that depend on other files.
- Java files retain their original source contents and filenames. They have been grouped by their apparent topic, not rewritten.
- Package declarations are preserved. Some folders may contain files from different Java packages, so do not assume every folder compiles as one project.
- Before making this repository public, review `INVENTORY.csv` and the files marked for review, especially `personalinformation.java` and temporary/alternate files.
- There are no exact byte-for-byte duplicate files in the uploaded ZIP, but several filenames suggest alternate versions.

## Folder guide
| Folder | Contents |
|---|---|
| `01_fundamentals` | Basic Java syntax, arithmetic, formatting |
| `02_conditionals_loops` | If/else, switch, loops, control flow |
| `03_strings_text` | String processing, text utilities, number words |
| `04_oop_classes` | Classes, objects, constructors, inheritance |
| `05_arrays_collections` | Arrays, sets, maps, collection exercises |
| `06_data_structures_algorithms` | Linked lists, stacks, queues, trees, hashing, histograms |
| `07_file_io_data` | Reading/writing files and data processing |
| `08_mini_applications` | Small calculators, simulations, and console programs |
| `09_gui_interactive` | Swing/JOptionPane and interactive programs |
| `10_assets` | Non-code assets from the original ZIP |
| `90_review_before_upload` | Files needing inspection before deciding where they belong |
